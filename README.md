# Funky portfolio

Abishek S, AI Engineer. A dark noir-and-crimson portfolio whose page is rebuilt live by a swarm of
cursors on every load: boxes drawn with size badges and ruler guides, text typed in, building as you
scroll. When it's done, the cursors follow your pointer.

```bash
npm install
npm run dev      # http://localhost:5175
npm run build    # -> dist/
```

Add `?swarm=off` to the URL to skip the build animation (it's also skipped for reduced motion).
